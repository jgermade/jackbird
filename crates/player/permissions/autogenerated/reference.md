## Default Permission

Every command of the phone's player, and its events.

#### This default permission set includes the following:

- `allow-set-queue`
- `allow-set-upcoming`
- `allow-play`
- `allow-pause`
- `allow-seek`
- `allow-stop`
- `allow-status`
- `allow-set-output`
- `allow-output-info`
- `allow-register-listener`
- `allow-remove-listener`
