# Session: Integrated Selection Toolbar, ESC Deselect & Batch Metadata Editing

**Date**: 2026-08-11 14:00
**Summary**: Seamless sticky selection action bar, Escape key track deselection, and multi-track batch metadata editor with common fields.

## Problem Statement

1. **Selection Toolbar Styling**: The current `.detail-action-bar` renders as a floating island with rounded borders and margins. It should be seamlessly integrated full-width at the top of the detail pane without floating separation.
2. **Deselection Shortcut**: Users expect pressing the `Escape` key to clear active track selections.
3. **Batch Metadata Editing**: When multiple tracks are selected, clicking "Editar" opens a modal displaying `"No hay pista seleccionada para editar"`. It should open the exact same metadata editing form populated with common values shared across all selected tracks (or `"(Varios valores)"` placeholders for differing fields), updating all selected tracks upon save.

## Goals

1. **Integrated Action Bar**: Redesign `.detail-action-bar` CSS to fit edge-to-edge as a sticky header at the top of `.detail-pane`.
2. **Keyboard Shortcut**: Listen for `Escape` keydown to clear active selection when no modal dialog is open.
3. **Multi-Track Batch Editing**:
   - Update `MetadataEditModal` & `MetadataEditor` to handle `tracks: Mp3Track[]`.
   - Calculate common values across selected tracks for form initial state.
   - Batch-write updated metadata across all selected tracks in VFS, recalculating dual checksums and updating `.meta/mp3-manager.json` snapshot.

## Implementation Plan

1. **Integrated Selection Toolbar Styling (`src/styles.css`)**:
   - Remove `border-radius`, floating margins, and floating shadow from `.detail-action-bar`.
   - Style as a sticky full-width header bar (`margin: -1.25rem -1.25rem 1rem -1.25rem; border-bottom: 1px solid var(--line)`).

2. **Escape Key Deselection (`src/views/Mp3ManagerView.tsx`)**:
   - Add global `keydown` event listener for `Escape`.
   - Clear `selectedTrackIds` and `selectedTrackId` when pressed while no modal dialog is open.

3. **Multi-Track Metadata Editing (`MetadataEditModal.tsx`, `MetadataEditor.tsx`, `Mp3ManagerView.tsx`)**:
   - Update `MetadataEditModal` to accept `tracks: Mp3Track[]`.
   - Implement common fields computation:
     - For each field (`title`, `artist`, `album`, `year`, `genre`, `trackNumber`, `coverDataUrl`), if all selected tracks share the same value, pre-fill it. Otherwise leave empty with `"(Varios valores)"` placeholder.
   - Update `handleSave` in `Mp3ManagerView.tsx` to handle multi-track saves:
     - Iterate through `selectedTracks`, apply modified/non-empty fields to each track, write bytes to VFS, recompute dual checksums, update snapshot, and save.
