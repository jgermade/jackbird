# Session: Tabs per root + flat/wizard grouping

Date: 2026-08-01 15:05
Status: In Progress

## Context
User requested a layout review and implementation for:
- tab navigation where each tab is a root folder
- flat/wizard grouping mode

4. Build derived album/disc hierarchy from track metadata (fallback to path/track number parsing).
5. Keep metadata editing and save semantics per selected file.
6. Adapt left panel UI:
   - flat: current table-like listing
   - wizard: album/disc grouped list with selectable tracks
7. Add lightweight styles for tabs, mode switch, and grouped rows.
8. Run type checks and fix any regressions.
